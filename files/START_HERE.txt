GETTING STARTED (5 MINUTES)
===========================

Step 1: Read This First
  → README.md (Project overview)

Step 2: Quick Setup
  → QUICK_START.md (Follow 5-minute setup)

Step 3: Start Backend
  $ cd backend
  $ mvn spring-boot:run
  
  Wait for: "Tomcat started on port(s): 8080"

Step 4: Start Frontend
  Option A: VS Code Live Server (recommended)
    - Open index.html in VS Code
    - Right-click → "Open with Live Server"
  
  Option B: Python
    $ cd frontend
    $ python -m http.server 5500
  
  Option C: http-server
    $ npm install -g http-server
    $ cd frontend
    $ http-server -p 5500

Step 5: Test
  → Open http://localhost:5500/index.html
  → Sign up, login, test features

That's it! System is working!

BACKEND → FRONTEND COMMUNICATION
================================
Frontend: http://localhost:5500 (Your SPA)
Backend:  http://localhost:8080 (Spring Boot API)
Database: Oracle with AMS schema

Frontend makes HTTP requests to:
  /api/auth/login
  /api/appointments
  /api/officials
  ... and more (see API_CONTRACT.md)
